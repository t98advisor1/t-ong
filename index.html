📘 AI 활용 안내

AI 비서로 할 수 있는 일

T-ong 오른쪽에 열리는 채팅창에서 말로 부탁하면 AI가 글을 쓰고, 필요하면 T-ong 기능을 직접 실행합니다.

  • 📢 알림장 작성: "내일 체육복 챙기라고 알림장에 넣어 줘"
  • 📅 일정 조회·추가: "이번 주 일정 알려 줘", "다음 주 수요일 학부모 총회 넣어 줘"
  • ✍️ 글쓰기: 조회 멘트, 가정통신문, 상담 기록 정리

알림장을 바꾸거나 일정을 추가할 때는 실행 전에 확인 버튼이 나오고, 선생님이 누를 때만 반영됩니다.

여는 방법

  • 상단 🤖 AI ▾ → AI 비서 열기
  • 자리배치 화면 왼쪽 메뉴의 🤖 아이콘

처음 한 번 준비

AI 비서는 선생님 본인의 Claude API 키로 동작합니다. API 키 발급 탭을 따라 키를 만든 뒤 AI 비서의 ⚙️ 설정에 붙여넣으면, 그 기기에서는 다음부터 바로 쓸 수 있습니다.

API 키는 Claude Pro 같은 구독과 별개입니다. 사용한 만큼만 요금이 나가는 방식이며, 선생님 계정의 카드로 결제됩니다.

1. Claude Console 가입

console.anthropic.com에 접속해 이메일이나 Google 계정으로 가입·로그인합니다.

2. 결제 수단 등록 · 크레딧 충전

Settings → Billing에서 카드를 등록하고 크레딧을 충전합니다. 소액(예: 5달러)만 충전해 두면 충전한 만큼만 쓰여서 안심하고 시작할 수 있습니다.

3. 사용 한도 정하기 (권장)

Settings → Limits에서 월 사용 한도를 정해 두면 예상보다 많이 쓰는 일을 막을 수 있습니다.

4. API 키 만들기

  1. API Keys → Create Key를 누르고 이름을 T-ong처럼 정합니다.
  2. sk-ant-로 시작하는 키가 나오면 바로 복사합니다. 이 화면을 닫으면 다시 볼 수 없습니다.

5. T-ong에 붙여넣기

🤖 AI 비서 → ⚙️ 설정 → API 키 칸에 붙여넣고 저장을 누릅니다. 키는 이 기기의 브라우저에만 저장되고 T-ong 서버로는 보내지 않습니다. PC와 태블릿처럼 기기가 다르면 기기마다 한 번씩 넣어 주세요.

요금은 얼마나 나오나요?

AI 비서는 기본으로 가장 저렴한 Haiku 5.5를 씁니다. 질문과 답변 길이에 따라 다르지만, 알림장 한 건 기준 대략 Haiku 5.5는 1원 안팎, Sonnet 5.5는 십여 원, Opus 5.5는 수십 원입니다. ⚙️ 설정에서 모델을 바꿀 수 있습니다. 실제 사용량과 요금은 Console의 Usage에서 확인할 수 있습니다.

키 관리 주의

  • 키는 비밀번호와 같습니다. 메신저나 문서에 붙여넣어 공유하지 마세요.
  • 여러 사람이 쓰는 교실 PC에서는 ⚙️ 설정의 이 기기에 키 저장을 끄고 쓰세요.
  • 키가 유출된 것 같으면 Console의 API Keys에서 해당 키를 삭제하고 새로 만드세요.

💡 Console 화면의 메뉴 이름은 Anthropic의 업데이트에 따라 조금 달라질 수 있습니다.

G OAuth 클라이언트 ID 연결 방법

Google Cloud에서 한 번만 설정하면 T-ong 사용자는 Google 계정 연결 버튼만 누르면 됩니다.

먼저 확인Google Cloud 프로젝트 소유자 계정으로 진행하세요. 아래 이미지는 2026년 Google Cloud 메뉴를 바탕으로 만든 화면 예시이며 메뉴 위치는 바뀔 수 있습니다.
  1. 1

    Google Calendar API 사용 설정

    API 및 서비스 → 라이브러리에서 Google Calendar API를 검색한 뒤 사용을 누릅니다.

    Google Calendar API 열기 ↗
  2. 2

    Google Auth Platform 동의 화면 설정

    브랜딩에서 앱 이름을 T-ong 교무수첩으로 입력합니다. 대상은 여러 선생님이 사용하므로 외부를 선택하고, 시험 중에는 사용할 Google 계정을 테스트 사용자로 추가합니다.

    데이터 액세스에는 이메일·openid와 calendar.events.owned(소유한 캘린더 일정 보기·수정) 범위를 등록합니다.

    Google Auth Platform 열기 ↗
  3. 3

    웹 애플리케이션 클라이언트 만들기

    클라이언트 → 클라이언트 만들기 → 웹 애플리케이션을 선택합니다. 승인된 JavaScript 원본에는 아래 주소를 경로 없이 각각 등록합니다.

    https://t-ong.vercel.apphttp://localhost:4321

    내부망 주소(예: 192.168.x.x)는 승인 원본으로 사용할 수 없습니다.

    OAuth 클라이언트 화면 열기 ↗
  4. 4

    클라이언트 ID를 복사해 T-ong에 저장

    …apps.googleusercontent.com으로 끝나는 클라이언트 ID만 복사합니다. T-ong의 앱 관리자 설정에 붙여넣고 저장한 뒤 Google 계정 연결을 누릅니다.

    Client Secret은 입력하거나 공개하지 마세요. T-ong의 브라우저 방식에서는 사용하지 않습니다.

연결이 안 될 때 확인하세요

  • origin_mismatch — 현재 주소와 승인된 JavaScript 원본이 정확히 같은지 확인합니다.
  • access_denied — 외부 앱 시험 상태라면 Google Auth Platform의 테스트 사용자에 계정을 추가합니다.
  • 403 / Calendar API — 현재 프로젝트에서 Google Calendar API가 사용 설정됐는지 확인합니다.
  • 여러 선생님에게 공개하기 전에는 Google의 OAuth 앱 확인 또는 검증이 필요할 수 있습니다.
이미지를 누르면 원본 크기로 열립니다.

    1
    나이스(NEIS) 교무업무시스템 접속 인증서로 나이스 시스템에 로그인합니다.
    2
    [교육과정] 메뉴 클릭 상단 주 메뉴에서 [교육과정]을 선택하고 좌측 하위 메뉴의 [시간표관리]를 클릭합니다.
    3
    [학생별시간표조회] (또는 학생별시간표출력) 해당 메뉴를 클릭하여 조회 화면으로 이동합니다.
    4
    학년 및 반 선택 후 [엑셀 다운로드] 담당 학년과 반을 선택하고 화면 우측 상단의 [엑셀 다운로드] 버튼을 클릭하여 저장합니다.
    5
    T-ong 업로드 창에 드래그 다운로드된 .xlsx 파일을 T-ong 학생별 시간표 업로드 점선 영역으로 끌어다 놓으면 1초 만에 파싱이 완료됩니다.
